# Mean-Variance-Standard Deviation Calculator

This project is a part of the **FreeCodeCamp Data Analysis with Python Certification**.

It calculates the **mean**, **variance**, **standard deviation**, **maximum**, **minimum**, and **sum** for each row, each column, and the flattened 3x3 matrix using NumPy.

---

## 📁 Files

- `main.py` – For running the project and testing
- `mean_var_std.py` – Contains the `calculate()` function

---

## 🚀 How to Run

Make sure Python and NumPy are installed. Then run:

```bash
python main.py
